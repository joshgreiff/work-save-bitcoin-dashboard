# Content strategy

Daily / episode workflow the site supports:

1. **Portfolio value update** — publish a new episode snapshot and refresh current portfolio fields.
2. **Market performance** — update contribution-adjusted and cash-flow-matched comparisons vs BTC, SPY, GLD using the same valuation timestamp.
3. **Bitcoin-per-share exposure** — refresh issuer metrics with citations; show look-through sats.
4. **Bitcoin Reserve growth** — append reserve transactions; never mix into portfolio P&L.
5. **Income potential** — re-run the income model on current deployable value.
6. **Latest investment question** — capture notes on the episode page for the recurring series narrative.
